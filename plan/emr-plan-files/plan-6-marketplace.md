## 20. Phase 6: content lifecycle and marketplace

Facts every Phase 6 chat needs: marketplace content is read-only and hash-pinned; hash = SHA-256 of canonical JSON of `content` (keys sorted, no whitespace); tiers are marketplace-verified, local-reviewed, local-draft; the server enforces read-only (the UI only mirrors it); reviewer is never the author; packages contain definitions only, never patient data.

#### [x] 42a5. Errors: band/rule/dose-like text without a references entry
*42a5 result (21 Nov 2026): no references sample was given, so the default shape is `content.references = [{id, citation}]` (both text, ids unique). A package needs a non-empty valid list when its content holds (a) a non-empty top-level `rules` list, (b) a key named `bands` (any depth, any case) with content, or (c) a text value that looks like a dose: a number followed by mg, mcg, µg, ug, g, ml, unit(s), iu, mmol or meq (for example "5 mg"; a plain unit such as "mL" or a word such as "dose" does not count).
