# EMR Enhancer — how to build in small steps

Each session, give Claude only TWO files:
1. `01-core.md` (about 1 page: the rules that never change)
2. ONE chunk file, e.g. `chunk-01-registration-screens.md`

Do not paste the big plan HTML or the whole repo. Claude reads only the files named in the chunk.

## Rules to save your limit
- One chunk per chat. Start a new chat for the next chunk.
- When a chunk is done, tick it in `02-roadmap.md` and note the result in one line.
- If a chunk feels too big, ask Claude: "split this chunk in two" before building.
- Ask for diffs/edits of named files, not full rewrites.

## Order
Do chunks in numeric order. Chunk 02 must come before any marketplace work.
